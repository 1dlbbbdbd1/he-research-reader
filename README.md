# 小何的科研助手

面向个人研究者的 Windows 科研 Agent。围绕一个课题持续对话，管理文献、证据、实验记录、研究决定和写作成果。每个研究文件夹独立保存资料、会话、已确认记忆及任务过程。

源码版本：**1.5.0，本地成品验收通过**。当前正式下载见 [GitHub Releases](https://github.com/1dlbbbdbd1/he-research-reader/releases/latest)。

## 从一个课题开始

1. 创建或打开研究项目，在设置中填写模型服务与 API Key，并完成连接测试。
2. 在对话中说明研究方向、导师要求、可用设备和时间。“立项”会帮助整理问题、未知条件、基线与阶段证据。
3. 打开“科研工作流库”选择“深度文献研究”，输入问题；可同时选择项目中的已解析资料。简单找论文也可以用“查文献”。
4. 阅读报告中的证据和原文摘录，结合全文核对；用“证据对比”“找思路”“设计实验”继续推进。
5. 实验后将日志、笔记、CSV、JSON、Markdown 或 TSV 交给“整理记录”，编辑草稿，确认后保存到课题实验记录。
6. 用“导师审查”检查证据缺口、替代解释和下一步。已确认成果与项目记忆会进入后续对话。

## 深度文献研究

Agent 先拆解问题并规划至多三组检索词，查询 Crossref 与 arXiv，再按已有结果补查至多两组。每组每库最多十条，共最多十次数据库请求。过程保留实际查询、时间、来源标识、去重及失败信息。

研究报告逐项展示主张、来源 ID、原文摘录、支持或反对关系，并单列待验证假设、证据缺口与下一步。程序核对摘录是否存在于本轮资料，错误摘录和空报告会进入待处理状态。结果区可展开阅读表格与来源链接，也可编辑并保存新版本；正文改动后原自动核验状态随之撤销。

出处匹配证明摘录可追溯，主张与摘录之间的语义关系、方法质量和适用条件仍需研究者核对；仅有数据库摘要时应结合全文使用。报告中的假设继续作为待验证建议。

长文按当前问题选取相关片段，显示原文字符位置和覆盖提示。每份资料保留独立来源，便于回查中段实验、首尾结论与未覆盖段落。

## 科研工作区

工作流库包含 **17 项科研辅助、10 项专项流程**，按任务调用 **7 个本地科研 Skills**。

| 研究环节 | 能做什么 |
| --- | --- |
| 选题与规划 | 立项、问题与假设、研究思路、实验方案、导师审查、阶段复盘 |
| 文献与证据 | 深度检索、多文献矩阵、论文阅读卡、引用核查、系统综述、证据关系与知识图谱 |
| 实验与数据 | 散乱记录整理、方法教学、可复现性检查、图表、数据分析方案、DID/RDD/IV/PSM/SCM 分析 |
| 写作与交流 | 提纲、结果讨论、组会材料、审稿回复、学术翻译、Word 排版、路线图与专利草案 |
| 持续积累 | 同项目会话、已确认记忆、成果历史、原始资料链接、实验时间线 |

项目 PDF 可自动发现并登记，也可手动扫描。阅读区支持 PDF 原文、结构化整理稿、版面对照、中英对照、批注和来源回跳。RIS、BibTeX 与 EndNote XML 用于导入题录；引用支持 GB/T、APA、IEEE 和 BibTeX。

专项流程会在开始前检查实际工具：Word 排版与相关 PDF 导出需要 Microsoft Word；本地翻译使用 Argos；因果分析需要 Python 与 NumPy；扫描 PDF 可通过 MinerU 解析。运行前检查会给出相应状态。具体合同与验证范围见 [工作台架构](docs/architecture/v2-agent-workbench.md)。

## 下载、数据与升级

在 [正式发布页](https://github.com/1dlbbbdbd1/he-research-reader/releases/latest) 下载 Windows x64 安装版或便携版，并用随包的 `SHA256SUMS.txt` 核对文件。

- 安装版适合日常使用，可选择目录、创建快捷方式和卸载；打包环境具备 Argos 时安装器提供可选本地翻译组件。
- 便携版直接运行。设置、最近项目和加密凭据保存在当前 Windows 用户的 AppData；研究库保存在你选择的文件夹，迁移电脑时需要单独备份。
- 升级前备份整个研究库，关闭旧程序后安装新版。数据库升级提供快照与校验；恢复方法见 [回滚说明](docs/migration/v1-rollback.md)。
- 安装包未商业签名，首次启动可能触发 SmartScreen；请从上述正式仓库下载。

AI 任务会将选中的资料、相关对话及项目上下文发送给所配置的模型服务。联网检索按任务授权访问数据库。API Key 由 Windows 系统能力加密保存；本地翻译在本机执行。原始研究数据和正式记录保留来源、版本和人工确认过程。

## 项目接口与验证进度

执行链为 `conversation-workflows → WorkbenchService → ToolRegistry → Research Vault`，数据库为 schema v19。模型、资料读取、运行恢复和成果版本复用同一套接口。

本轮先调研 Elicit、Consensus、Scite、GPT Researcher、Open Deep Research、Sakana AI Scientist 与 FutureHouse Robin，再补上多步检索、证据摘录检查和长文相关片段。[市场对比与实施记录](docs/agent-market-comparison-2026-09-06.md)说明采用理由、证据边界与验收状态。

当前已通过完整测试 277 项、生产构建、四档源码桌面验收及生产依赖审计（0 项漏洞）。真实模型完成两轮检索与自动修订，53 篇候选中形成 10 项出处匹配的主张；安装版和便携版已生成，目录版与便携版成品桌面验收通过；远端发布待完成。本地成品位于 `release-1.5.0-deep-research/`，目录内提供 `SHA256SUMS.txt`。详见 [本轮验收记录](docs/acceptance/deep-research-1.5.0.json)。

开发命令：

```powershell
npm ci
npm test
npm run build
npm run smoke:desktop
```

真实模型验收脚本为 `scripts/smoke-deep-research.cjs`，使用应用已有配置、独立临时研究库和公开研究问题，运行会消耗所配置服务的额度。历史验收见 [1.4.0 科研流程记录](docs/research-cycle-audit-2026-09-06.md)，版本变更见 [CHANGELOG](CHANGELOG.md)。
