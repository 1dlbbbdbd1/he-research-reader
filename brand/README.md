# H’s 科研助手品牌资源

## 定稿方向

品牌标记以大写 `H` 为主体：两根深海军蓝精密立柱代表稳定的研究工作台，紫色轨道代表跨文献检索与持续研究路径，右上圆形节点代表可回溯、可核验的证据锚点。

## 颜色

- 深海军蓝：`#101A4B`
- 轨道紫：`#623CFF`
- 渐变范围：`#4B2CFF` → `#875BFF`
- 暖白底色：`#FBFAF7`

明确不使用绿色、书本、学士帽、齿轮堆砌或通用 AI 星芒作为品牌主体。

## 文件用途

- `xiaohe-logo-mark.svg`：透明背景彩色主版，用于应用侧栏、网页和文档。
- `xiaohe-logo-mark-flat.svg`：无渐变纯色版，用于颜色受限或需要稳定复现的场景。
- `xiaohe-logo-mark-mono.svg`：单色版，用于印刷、雕刻或黑白输出。
- `xiaohe-app-icon.svg`：带安全底板的应用图标母版，用于生成 PNG 与 Windows ICO。
- `png/mark/`：16、24、32、48、64、128、256、512 像素透明标记 PNG。
- `png/app-icon/`：同样 8 档、带暖白安全底板的应用图标 PNG。
- `windows/xiaohe-research-reader.ico`：包含多尺寸的 Windows 应用图标。

## 使用规则

- 不拉伸、旋转或改变 `H` 与轨道的相对位置。
- 小于 24 px 时优先使用带底板的应用图标版。
- 透明主版四周至少保留标记高度 12% 的安全空间。
- 生成式探索图仅作为过程参考，不再作为正式品牌资源。

## 接入状态与验证

- 应用侧栏、网页页签、Electron 窗口和 electron-builder Windows 配置已经使用本套资源。
- 2026-08-01 已通过 16/24/32/48/64/128/256/512 px 导出检查，ICO 含 7 档尺寸。
- 900×700 窄窗口中标记实际显示约 32.4×32.4 px，无横向溢出；本地生产预览控制台无警告或错误。
