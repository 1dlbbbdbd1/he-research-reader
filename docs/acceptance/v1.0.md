## 数据安全门

- 迁移前快照使用数据库 SHA-256 命名并重复复用；迁移后执行 SQLite `quick_check` 与 `foreign_key_check`。
- `scripts/restore-migration-backup.ps1` 需要显式 `-Force`，校验研究库路径、BackupId、SHA-256 与文件占用，并先创建当前数据库救援副本。
- PDF、MinerU 原始 Markdown、原文证据和已确认历史均不可被 AI 覆盖；AI 草稿、建议关系与正式记录分层保存。
