## 本轮实现与验收计划

1. 深度文献研究：最多两轮，先生成至多三组检索词，再按证据缺口补查至多两组；每组 Crossref/arXiv 各最多十条。网址由程序生成，保留查询、时间、去重与失败记录。空响应、数据库故障和无效模型结构都必须可见。
2. 证据报告：每项观察使用真实候选 ID 和原文摘录，程序检查 ID 与摘录匹配。研究假设、冲突、下一步实验与缺失信息分别呈现；存入现有可编辑成果区。核验只证明出处，语义仍由研究者审查。
3. 长文材料：在总上下文预算内保留相关片段和字符位置，覆盖首尾以外的关键段；标明截取范围并保护各来源独立身份。
4. 发布：实现审查、故障回归、完整测试、构建、桌面和成品验证、README 与发布说明同步，通过后按用户授权提交、远端试打包、正式发布。旧产物保留。
