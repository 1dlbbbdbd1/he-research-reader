H’s 科研助手 - 可选本地翻译模块

本模块在安装时由用户明确选择，提供离线英文到中文翻译。

主要组件：
- Argos Translate 1.11.0：MIT License。许可证文件随 Python 环境保存在
  argos\.venv\Lib\site-packages\argostranslate-1.11.0.dist-info\LICENSE。
- CPython 3.12：Python Software Foundation License。许可证文件保存在
  python\<具体版本>\LICENSE.txt。
- English → Chinese 1.9 模型：基于 OPUS-MT，CC BY 4.0。
  作者、论文和许可说明保存在 packages\translate-en_zh-1_9\README.md。
- Python 依赖的许可证及元数据保存在各自的 *.dist-info 目录中。

本模块只在本机处理翻译文本，不需要第三方 API Token。
